# Niskenadi Trisna — UI/UX Designer Portfolio ✦

> *"The designer with the most freedom in this ocean creates the greatest experiences."* — **The Grand Line Philosophy**

A high-performance, minimalist editorial portfolio showcasing enterprise case studies, interactive tools, and design systems. Built with **React 19**, **Vite**, **Framer Motion**, and **WebGL Fluid Physics**.

---

## ✨ Features

- **Editorial Aesthetic:** Paired typography (`Instrument Serif` + `Plus Jakarta Sans`) with an obsidian dark theme.
- **Buttery-Smooth Performance:** GPU-accelerated scroll reveals, 60–120 FPS animations, and zero-overhead compositing.
- **Bento Grid Showcase:** Asymmetrical responsive showcase of live tools and experiments.
- **Interactive Fluid Physics:** Integrated `<SplashCursor />` WebGL simulation powered by GPU shaders.
- **Mobile & Tablet First:** Adaptive glass capsule navigation with mobile drawer menu.
- **Hairline Scroll Progress:** Real-time spring-physics scroll indicator.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Modern CSS (CSS Grid, Container Queries, Hardware-Accelerated Transforms)
- **Animations:** Framer Motion + WebGL Shaders
- **Typography:** Instrument Serif, Plus Jakarta Sans, One Piece Custom Font
- **Linter & Tooling:** Oxlint, Vite 8

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/BayDKen/portofolio-project.git

# Navigate to directory
cd portofolio-project

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
